# Zakres licencji i pochodzenie plików

Licencja MIT dotyczy autorskiego kodu moda: mostka C++/JNI, własnych klas Java,
narzędzi, instalatora i dokumentacji. Nie oznacza, że materiały gier stają się
open source.

| Grupa | Pochodzenie i zakres |
| --- | --- |
| Pet Soccer | Oryginalna gra jest osobnym, wymaganym produktem. Jej programy, silnik, biblioteki, środowisko Java i niezmienione klasy nie są dołączone jako kompletne pliki. Zmiany istniejących plików są stosowane do lokalnej instalacji użytkownika przez łatki. Prawa do gry pozostają przy jej właścicielach. |
| Gothic | Modele, tekstury i oryginalne kwestie głosowe pochodzą z materiałów Gothic. Adaptacja do formatu Pet Soccer nie zmienia praw do źródeł. |
| Minecraft | Modele/tekstury oparte na materiałach Minecraft; adaptowane bloczkowe postacie i moby. Prawa do materiałów źródłowych pozostają przy ich właścicielach. |
| Wiedźmin | Adaptowane oryginalne siatki/tekstury postaci Wiedźmina, m.in. z autorskich portów Workshop. Identyfikatory użytych źródeł i uwagi są opisane w `data/selected-rosters.json`. Nie przypisujemy tym zasobom licencji MIT. |
| Głosy nazw | Własne nagrania nazw przetworzone do barwy komentatora; referencyjna barwa pochodzi z oryginalnej gry. Surowe nagranie użytkownika, modele głosowe i checkpointy nie są publikowane. Nagrania w paczce nie są objęte ogólną deklaracją MIT dla kodu. |
| Czcionki i grafiki interfejsu | Materiały bazowej gry lub ich adaptacje. Zmiany istniejących plików są odtwarzane z instalacji użytkownika i łatki. Nowe aliasy mogą używać tych samych bitmap. Nie są relicencjonowane. |
| JNI | Nagłówki nie są vendoryzowane. Do kompilacji użyj zewnętrznego JDK i jego licencji. |
| Eclipse ECJ | Zewnętrzna zależność kompilacji Java. Kompilator nie jest dołączony do źródeł ani do uruchomienia gry. |
| NSIS / MSVC | Narzędzia budowania instalatora/mostka. Zachowują własne licencje. |

Nazwy gier i postaci identyfikują kompatybilność i zawartość fanowskiej paczki.
Projekt nie jest oficjalnym wydaniem żadnej z wymienionych gier.

prywatnych danych do publicznego zgłoszenia.
